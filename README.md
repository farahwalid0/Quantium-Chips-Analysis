# Quantium – Chips Category Analysis Dashboard

## Project Overview

This project focuses on analyzing customer purchasing behavior and sales performance within the chips category using retail transaction data. The goal is to gain valuable business insights, understand customer preferences, and identify purchasing patterns through an interactive Power BI dashboard.

## Objectives

- Analyze sales performance within the chips category.
- Understand customer purchasing behavior and preferences.
- Identify the most popular chip brands and products.
- Explore purchasing patterns across different customer segments.
- Analyze sales trends and transaction performance.
- Generate actionable insights to support business decisions.

## Tools Used

- Power BI
- Microsoft Excel
- Power Query (Data Cleaning & Transformation)

## Dashboard Features

- Chips category sales analysis.
- Customer purchasing behavior analysis.
- Brand and product performance analysis.
- Sales and transaction KPIs.
- Interactive filters and slicers.
- Data visualization and trend analysis.

## Project Files

- Power BI Dashboard (.pbix)
- Cleaned Dataset (.csv)
- Dashboard Screenshots

## Dashboard Preview

The dashboard provides an interactive overview of the chips category, allowing users to explore sales performance, customer preferences, and purchasing behavior to gain meaningful business insights.
